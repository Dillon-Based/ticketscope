- (decision) Topology: one codebase, one container image, two Deployments: api (retrieval + page; sole holder of DB connection and embedding model) and mcp (thin; no DB, no model; calls api over HTTP with W3C traceparent). Binds epics 1,3,4,5,6,7. Prevents MCP reaching the DB or reimplementing retrieval; makes the R8 trace cross a real service hop. User chose over in-process mount and two images.
- (constraint) Initiative ticket inherited silently: Postgres+pgvector on CloudNativePG, no server-side LLM, MCP 2026-07-28 stateless Streamable HTTP + OAuth 2.1, OIDC deploys/no stored keys, ephemeral EKS <10 USD/mo, cut order Grafana>OAuth>EKS>eval gate, public material only, claim discipline wording
- (decision) Corpus source of truth: manual ingest job pulls GitHub issues and publishes a versioned corpus snapshot as a GitHub Release asset; a load job loads that snapshot into Postgres in every environment (kind CI, EKS). Embeddings are a derived cached artifact keyed by (snapshot version, model id, preprocessing version). Binds epics 1,2,3,5. Prevents eval scores drifting with a live corpus, GitHub rate limits in spin-up, and per-env divergent data. CNPG restore stays a separate recorded drill (R3), not the spin-up path. User chose over CNPG-restore and live re-ingest.
- (decision) DB write ownership: one plain-SQL migration track applied by a single migrate Job (Helm pre-install/pre-upgrade hook); the load job is the sole writer of corpus tables; api connects with a read-only role; epic 3 adds embedding column/index through the same track. Binds epics 1,3,5. Prevents two schema owners, migration races between replicas, api mutating corpus. User chose over Alembic and migrate-on-start.
- (decision) Paradigm: ports and adapters. core (retrieval modes, fusion, result model) imports nothing outside itself; ports: CorpusStore, Embedder; adapters: postgres, embedder model, http (FastAPI + page), mcp; batch jobs (ingest, load, eval) are thin drivers over core. Eval scores core through the real postgres adapter (p95 includes DB, excludes HTTP). Binds all epics. Prevents retrieval logic leaking into routes/MCP tools and eval measuring something other than the shipped retrieval path. User chose over simple layered.
