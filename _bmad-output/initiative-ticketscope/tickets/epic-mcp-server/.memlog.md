- (requirement) R1 (parent R4): search_similar_issues(query, mode?, k?) at /mcp returns the /v1/search body with a contract-generated schema; met by the CI client test on kind with and without a mode
- (requirement) R2 (parent R4): get_issue takes the readable key and returns that issue and outcome; met when the CI test fetches a key taken from a search result
- (requirement) R3 (parent R4): failed tool calls are MCP tool errors with the API's problem detail; met for unknown mode, unknown key and unreachable API in CI
- (requirement) R4 (parent R4): Claude Desktop through a fixed-hostname tunnel to kind calls search_similar_issues and answers; met by a recorded session
- (requirement) R5 (parent R8): one trace from the MCP tool call through the HTTP hop, retrieval and the DB, continuing _meta trace context; met by a CI check in Tempo

- (decision) get_issue takes the key read from url, with no column or reload; a key column was declined because it forces a reload, a baseline update and a new embedding asset (user, 2026-11-10)
- (decision) Tunnel is ngrok's free static domain, with Tailscale Funnel as the fallback; Cloudflare was declined because it needs DNS on Cloudflare, conflicting with epic 5's Route53 zone (user, 2026-11-10)
- (decision) Unattended bmad-loop build with plan checkpoints on stories 1, 2 and 4 (user, 2026-11-10)
